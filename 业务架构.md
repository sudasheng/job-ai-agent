# 求职 AI Agent — 业务架构

## 一、系统总览

```
┌──────────────────────────────────────────────────────────────┐
│                      用户入口（Jinja2 前端）                    │
│   /       /login     /job-search     /interview     /chat    │
├──────────────────────────────────────────────────────────────┤
│                    FastAPI (app/main.py)                      │
│  CORS 中间件 ｜ 全局异常处理 ｜ 生命周期管理 ｜ 静态文件挂载      │
├──────────────────────────────────────────────────────────────┤
│  API v1 (/api/v1)                                            │
│  ├── /auth      → 注册 / 登录 / Token 刷新 / 用户信息           │
│  ├── /jobs      → 岗位搜索 / 列表 / 详情 / 向量化               │
│  ├── /interview → 面试会话管理 / 答题 / 评分                    │
│  └── /chat      → 对话发送 / 流式回复 / 历史记录                 │
├──────────────────────────────────────────────────────────────┤
│  Service 层                                                   │
│  UserService ｜ JobService ｜ InterviewService ｜ ChatService  │
│  RAGService                                                   │
├──────────────────────────────────────────────────────────────┤
│  Agent 层 (app/agent/)                                       │
│  JobAIAgent → LangChain create_openai_tools_agent            │
│  ├── scrape_jobs_by_keyword     (Skill)                      │
│  ├── scrape_job_detail_by_url   (Skill)                      │
│  ├── generate_interview_questions (Skill)                    │
│  └── score_interview_answer     (Skill)                      │
├──────────────────────────────────────────────────────────────┤
│  基础设施层                                                    │
│  ├── LLM:    DeepSeek (ChatOpenAI 兼容接口)                    │
│  ├── RAG:    ChromaDB + 千问 Embedding + 多路检索              │
│  ├── Crawler: Playwright → Boss 直聘                          │
│  ├── DB:     MySQL 8.0 (SQLAlchemy 异步)                      │
│  └── Auth:   JWT (Access + Refresh Token) + bcrypt            │
└──────────────────────────────────────────────────────────────┘
```

## 三、闭环业务流程

### 闭环 1：岗位搜索与分析

```
用户输入关键词/URL
  │
  ▼

├───────────────────────────────────────────────────────────────┤
│  ├── 有 url → 直接抓取岗位详情                                  │
│  └── 无 url → 按关键词搜索岗位列表                              │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 2 ──────────────────────────────────────────────────────┐
│ Service: JobService.search_and_scrape()                       │
│ 文件: app/services/job_service.py:28-82                       │
├───────────────────────────────────────────────────────────────┤
│  ├── 启动 Playwright 浏览器                                    │
│  │   文件: app/crawler/boss_crawler.py → BossZhipinCrawler     │
│  ├── 检查登录状态 (Cookie 持久化)                               │
│  │   文件: app/crawler/boss_crawler.py:142-154                │
│  ├── 搜索岗位列表 / 抓取岗位详情                                │
│  │   文件: app/crawler/boss_crawler.py:158-207                │
│  ├── BeautifulSoup 解析 HTML 提取字段                          │
│  │   文件: app/crawler/boss_crawler.py:244-408                │
│  ├── 去重检查 (source_id)                                     │
│  └── 持久化到 MySQL (jobs 表)                                  │
│      模型: app/models/job.py → Job                            │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 3 ──────────────────────────────────────────────────────┐
│ 前端 → POST /api/v1/jobs/{job_id}/vectorize                   │

│  │   文件: app/rag/embeddings.py                               │
│  └── 存入 ChromaDB (持久化模式)                                 │
│      文件: app/rag/vector_store.py:47-62                       │
│      标记 jobs.is_vectorized = True                            │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 4 ──────────────────────────────────────────────────────┐
│ 前端 → GET /api/v1/jobs?keyword=&city=&page=&page_size=       │
│ 文件: app/api/v1/jobs.py → list_jobs()                         │
│ 支持: 关键词模糊搜索、城市筛选、分页                             │
└───────────────────────────────────────────────────────────────┘
```

### 闭环 2：面试练习（完整闭环）

```
用户创建面试会话
  │
  ▼
┌─ Step 1 ──────────────────────────────────────────────────────┐
│ 前端 → POST /api/v1/interview/sessions                         │
│ 文件: app/api/v1/interview.py → create_session()               │
│ 参数: { direction, job_id, question_count, question_types }   │
│ 认证: require_user (JWT)                                      │
├───────────────────────────────────────────────────────────────┤
│  ├── 获取关联岗位信息 (如有 job_id)                             │
│  │   Job.to_search_text() → 拼接岗位描述全文                    │
│  ├── 创建 InterviewSession 记录                                │
│  │   模型: app/models/interview.py:14-59                       │
│  └── 调用 _generate_questions() → 见 Step 2                   │
│      文件: app/services/interview_service.py:170-209           │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 2a ─────────────────────────────────────────────────────┐
│ RAG 多路检索（有数据支撑）                                      │
│ 文件: app/rag/retriever.py → MultiPathRetriever.retrieve()    │
├───────────────────────────────────────────────────────────────┤
│  ├── Query 改写 (LLM)                                         │
│  │   将用户方向改写为 3-5 个不同检索视角                        │
│  │   Prompt: app/llm/prompts.py → QUERY_REWRITE_*             │
│  ├── 多路向量检索                                              │
│  │   对每个改写查询，在 ChromaDB 多集合中检索                    │
│  │   文件: app/rag/vector_store.py:87-106                      │
│  ├── 结果去重合并                                              │
│  │   按 source_id 去重，按相似度分数排序                        │
│  └── 返回 Top-K 知识片段                                       │
│      文件: app/rag/retriever.py:51-96                          │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 2b ─────────────────────────────────────────────────────┐
│ LLM 生成面试问题                                               │
│ 文件: app/services/interview_service.py:_generate_questions() │
├───────────────────────────────────────────────────────────────┤
│  ├── 模型: DeepSeek (ChatOpenAI 兼容接口)                      │
│  │   文件: app/llm/deepseek.py → create_deepseek_llm()         │
│  ├── Prompt: 面试问题生成                                      │
│  │   文件: app/llm/prompts.py:11-81                           │
│  │   - 有 RAG 数据: INTERVIEW_QUESTION_WITH_KNOWLEDGE_HUMAN   │
│  │   - 无 RAG 数据: INTERVIEW_QUESTION_HUMAN                  │
│  ├── LLM 输入: { job_info, direction, question_count,         │
│  │              question_types, difficulty, knowledge_context }│
│  ├── LLM 输出: JSON → { questions: [{ sequence, question_text, │
│  │              question_type, reference_answer }] }          │
│  └── 保存到 MySQL (interview_questions 表)                      │
│      模型: app/models/interview.py:62-101                      │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 3 ──────────────────────────────────────────────────────┐
│ 用户逐题回答                                                   │
│ 前端: /interview 页面展示问题列表，用户输入答案                  │
│ 文件: app/templates/interview.html                             │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 4 ──────────────────────────────────────────────────────┐
│ 前端 → POST /api/v1/interview/sessions/{session_id}/answer    │
│ 文件: app/api/v1/interview.py → submit_answer()                │
│ 参数: { question_id, user_answer }                            │
├───────────────────────────────────────────────────────────────┤
│  ├── 保存用户回答到 interview_questions.user_answer            │
│  ├── 调用 _score_answer() → 见 Step 5                         │
│  │   文件: app/services/interview_service.py:211-231           │
│  ├── 返回评分结果: { score, comment, passed }                  │
│  └── 更新会话进度 (answered_questions++)                       │
│      全部答完 → 计算平均分 → status = "completed"               │
│      文件: app/services/interview_service.py:244-258           │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 5 ──────────────────────────────────────────────────────┐
│ LLM 评分                                                      │
│ 文件: app/services/interview_service.py:_score_answer()       │
├───────────────────────────────────────────────────────────────┤
│  ├── 模型: DeepSeek                                           │
│  ├── Prompt: 面试评分                                         │
│  │   文件: app/llm/prompts.py:87-125                          │
│  │   评分维度: 准确性(40%) + 深度(30%) + 表达(20%) + 实践(10%) │
│  ├── LLM 输入: { question_text, reference_answer,             │
│  │              knowledge_context, user_answer }               │
│  └── LLM 输出: JSON → { score, comment, strengths,            │
│                        improvements, accuracy, depth, ... }    │
└───────────────────────────────────────────────────────────────┘
```

## 四、RAG 检索管线（完整流程）

```
用户查询: "Python 后端开发"
  │
  ▼
┌─ Step 1: Query 改写 ──────────────────────────────────────────┐
│ 文件: app/rag/retriever.py:34-49                              │

├───────────────────────────────────────────────────────────────┤
│ 输入: { user_input: "Python 后端开发", direction: "Python" }  │
│ 输出: {                                                       │
│   rewritten_queries: ["Python 后端开发",                       │
│     "Django Flask 框架", "REST API 微服务", "Python 面试题"],  │
│   keywords: ["Python", "后端", "Django", "Flask"],            │

│ }                                                             │

  │
  ▼
┌─ Step 2: 多路向量检索 ────────────────────────────────────────┐

│ 文件: app/rag/vector_store.py:87-106                          │
├───────────────────────────────────────────────────────────────┤
│ 对每个改写查询，在 ChromaDB 多集合中检索:                       │
│  ├── 默认集合: settings.CHROMA_COLLECTION_NAME                │

│  ├── Embedding: 千问 text-embedding-v3 (DashScope)            │
│  │   文件: app/rag/embeddings.py                               │

└───────────────────────────────────────────────────────────────┘
  │
  ▼

│ 文件: app/rag/retriever.py:86-92                              │
├───────────────────────────────────────────────────────────────┤
│  ├── 按 metadata.id 去重（同一文档只保留一条）                  │
│  ├── 按 similarity score 排序（分数越低越相似）                 │
│  └── 截断返回 Top-K 结果                                      │
└───────────────────────────────────────────────────────────────┘
  │
  ▼
┌─ Step 4: 传递给 LLM ──────────────────────────────────────────┐
│ 文件: app/llm/prompts.py:53-81                                │
│ 知识上下文作为 knowledge_context 注入 Prompt                   │
│ LLM 基于检索到的知识生成有据可依的面试问题                      │
└───────────────────────────────────────────────────────────────┘
```
